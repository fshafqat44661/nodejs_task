Humble Superhero API

🚀 Project Overview

This is a simple React-based app that allows users to add superheroes with their name, superpower, and humility score. The superheroes are displayed in a sorted list based on their humility score (descending order).

🛠️ Installation & Setup

Clone the repository:

git clone https://github.com/your-repo/humble-superhero-api.git
cd humble-superhero-api

Install dependencies:

npm install

Start the development server:

npm start
